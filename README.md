# 算法随行 · Android 安装包

用于在 Android 手机上阅读算法题与题解，支持 CF、洛谷、中文翻译和离线阅读。最低系统为 Android 8.0。

本仓库仅发布 APK、版本说明、版本清单和校验文件。源码保存在独立私有仓库。

## 当前版本

当前版本为 **1.2.3**，版本号为 **8**。本次修复 VJudge 已授权用户导入比赛目录时被误判为无权限的问题。

本版通过 150 项本地单元测试，未在已授权的私人比赛及手机上验证。持久后台题目下载、OJ 账号同步和个人备份仍待后续开发。具体范围见 Release 更新说明。

## 下载与安装

在本仓库的 Releases 页面选择版本，下载 `algorithm-reader-1.2.3.apk`，在手机上打开并按系统提示安装。

安装包沿用原包名和个人调试签名。新版可覆盖安装，保留原有学习数据。请保留应用，直接安装新版；卸载会删除本地数据。

## 应用内更新

1.1.2 及以上版本已包含更新器。在“我的 → 应用更新”查看并选择已发布的兼容版本；旧界面入口位于“设置 → 应用更新”。

1.1.1 及更早版本需先手动覆盖安装一次。安装包由系统后台下载，安装前会校验文件大小、摘要、包名、版本和签名。

版本清单位于根目录 `versions.json`。历史版本继续保留，Android 不允许直接降级覆盖。

APK 的 SHA-256 校验值随 Release 提供。源码、签名私钥和访问令牌不在本仓库分发。
