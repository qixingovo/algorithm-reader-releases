# 算法随行 · Android 安装包

用于在 Android 手机上阅读算法题与题解，支持 CF、洛谷、中文翻译和离线阅读。最低系统为 Android 8.0。

本仓库仅发布 APK、版本说明和校验文件。应用源码保存在独立私有仓库。

## 下载与安装

在本仓库的 Releases 页面选择版本，下载 `algorithm-reader-版本号.apk`，在手机上打开并按系统提示安装。

安装包沿用个人调试签名。相同包名、相同签名的新版可覆盖安装，保留原有学习数据。请以更新说明中的功能为准。

## 应用内更新

1.1.1 没有应用内更新器。带更新器的版本发布后，先手动覆盖安装一次，即可从设置中的“应用更新”选择后续版本。

版本清单为根目录的 `versions.json`。历史版本可查看，Android 不允许直接降级覆盖。

APK 的 SHA-256 校验值随 Release 提供。源码包、签名私钥和访问令牌不在本仓库分发。
